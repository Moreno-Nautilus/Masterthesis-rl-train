# ===== WEEKEND CHAIN (2026-08-07) — fix hole-finding under the REQUIRED 2.5cm anchor noise ===========
# DIAGNOSIS (measured): the 2.5cm socket-anchor noise is THE killer, NOT the 192 solver. g25t12 (our 80%
# policy, trained @1cm) = 77% @1cm but 28% @2.5cm; s192 (trained @2.5cm from scratch) = 29%. So
# from-scratch @2.5cm is uncrackable -> learn hole-finding at low noise and RAMP (noise curriculum).
#
# BAKED INTO ALL 4 RUNS (the deploy-faithful fixes):
#   - NOISE CURRICULUM: fixed_asset_pos_obs_noise ramps _start[1cm] -> _bound[2.5cm] over 128000 control
#     steps (~1000 it), then constant 2.5cm (the real requirement). cfg _start/_bound in cooling_tasks_cfg.
#   - GRAVITY COMP (use_gravity_comp=True): subtract the pre-contact gravity wrench from ft_force -> pure
#     CONTACT force obs, matching the real robot's gravity-compensated F/T (else a sim-only gravity offset).
#   - LATERAL-CENTERING reward (e2e_reward_center_weight): pull the tip OVER the hole (attacks the miss).
#   - CAD cam (locked), tilt curric 0->20deg, weld+grasp DR (25deg + jitter), friction DR, softer PD,
#     action 0.01, seat bonus 0.5 (Run 3 raises it), success 0.25 (=head-flush, real shaft 3mm<hole).
#   - solver 192 (realistic contact) on Runs 1-3; Run 4 = 128 (proven-learnable soft-contact SAFE fallback).
#
# RUN VARIANTS: 1=core (center 20), 2=EXPLICIT ESTIMATOR (clean A/B vs w1: identical recipe + a supervised
#   hole-pose estimator head whose prediction is fed into the policy), 3=HEAVY CENTERING (center 50 — the
#   direct hole-finding push, attacks the observed "misses the hole" failure; picked over a seat-bonus run,
#   which targets a commit-the-last-mm failure we do NOT see in the videos), 4=128 safe base (center 20).
# ESTIMATOR (w2): the aux head off the CNN features regresses the TRUE tip->socket gap (aux_label[1:4], the
#   clean pose the wrist cam sees) and its DETACHED prediction is concatenated into the policy input, so the
#   policy gets a vision-predicted socket location instead of only the +-2.5cm anchor. Needs a DIFFERENT task
#   (estimator agent yaml w/ aux_head + aux_label obs) -> 8th per-row TASK field + env.e2e_keep_aux_label=True.
#   2000 it each (~14-21h) -> the 4 runs fit the 72h weekend.
